СМЕНА НА ЗАВОДЕ — Android-проект

Проект содержит вашу игру в app/src/main/assets/index.html и оболочку Android WebView.

Сборка APK в облаке с телефона (через GitHub Actions):
1. Откройте https://github.com/ и войдите или создайте аккаунт.
2. Создайте новый репозиторий (New repository), например SmenaNaZavode. Для простоты можно выбрать Public; не загружайте сюда секретные данные.
3. Распакуйте этот ZIP на телефоне с помощью приложения «Файлы» / архиватора.
4. Загрузите содержимое папки SmenaAndroid в репозиторий, сохраняя структуру каталогов. Важно: загрузить именно файлы проекта, а не один ZIP.
5. После загрузки откройте вкладку Actions в репозитории. Если GitHub попросит разрешить Actions, подтвердите.
6. Запуск сборки обычно начинается автоматически после загрузки файлов в ветку main/master. Также можно открыть Build Android APK → Run workflow.
7. Откройте завершившийся запуск workflow, прокрутите до Artifacts и скачайте SmenaNaZavode-APK.
8. Распакуйте скачанный архив артефакта. Внутри будет app-debug.apk.
9. Откройте APK на телефоне. Если Android попросит разрешение, разрешите установку неизвестных приложений для браузера/файлового менеджера, которым вы открываете APK.

Если загрузка папок с телефона неудобна, можно использовать компьютер или попросить человека загрузить файлы проекта в GitHub.

Примечание: это debug APK для личной установки, не подписанный релиз для публикации в Google Play.
